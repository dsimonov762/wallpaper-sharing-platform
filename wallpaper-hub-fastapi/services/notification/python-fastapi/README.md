# notification-service (Python / FastAPI)

Wallpaper Hub notification-service: event-driven emails, in-app inbox, live push. Redis is the
primary database. See the repository README (sections 3, 4.4, 5.1, 6.5) and `CHEATSHEET.md`.

Run from the repository root:

```text
just notification-sync
just notification-run
just notification-check
just notification-test-integration
```
